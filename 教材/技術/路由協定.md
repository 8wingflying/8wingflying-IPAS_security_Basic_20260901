# 路由協定
## 靜態路由與動態路由

網路路由協定主要分為由管理員手動設定的**靜態路由**，以及透過演算法自動交換路徑資訊的**動態路由**。

### 靜態路由 vs. 動態路由

| | 靜態路由 (Static Routing) | 動態路由 (Dynamic Routing) |
|---|---|---|
| **設定方式** | 網路管理員手動逐一指定網路路徑 | 路由器互相交換資訊並自動學習網路拓撲 |
| **拓撲變更** | 需人工重新設定，否則路由會中斷無法連線 | 自動重新計算路徑並收斂至新路徑 |
| **系統負擔** | 極低（不佔用 CPU 與記憶體進行計算） | 較高（需消耗資源計算演算法與廣播更新） |
| **適用情境** | 小型網路、單一出口架構、高度安全需求 | 中大型網路、複雜且具備備援連線的架構 |
| **預設路由** | `0.0.0.0/0` 為最常見的特殊靜態路由 | 無此概念（均依賴動態學習） |

## 動態路由協定分類

根據運作的範圍，動態路由主要分為**內部閘道協定 (IGP)** 與**外部閘道協定 (EGP)**：

### 1. 內部閘道協定 (IGP, Interior Gateway Protocol)
負責在單一「自治系統 (AS)」內部進行路由資訊交換。

* **距離向量 (Distance Vector)**
  * **RIP (Routing Information Protocol)**：以「跳數 (Hop count)」計算最短路徑，最大限制 15 跳，適合早期或架構極簡單的小型網路。
  * **EIGRP (Enhanced IGRP)**：由 Cisco 開發的進階距離向量協定（現已開放標準），收斂速度極快，並兼具鏈路狀態的部分特性。

* **鏈路狀態 (Link-State)**
  * **OSPF (Open Shortest Path First)**：以網路介面頻寬作為成本，利用 Dijkstra 演算法計算無迴圈的最短路徑，是目前企業端最主流的 IGP。
  * **IS-IS (Intermediate System to Intermediate System)**：運作邏輯與 OSPF 類似，但擴充性極佳，常被大型 ISP（網際網路服務提供者）的骨幹網路採用。

### 2. 外部閘道協定 (EGP, Exterior Gateway Protocol)
負責在不同的「自治系統 (AS)」之間進行路由資訊交換。

* **路徑向量 (Path Vector)**
  * **BGP (Border Gateway Protocol)**：網際網路 (Internet) 唯一的核心路由協定。
  * 負責處理全球 ISP、跨國企業間極其龐大的路由表，其選路決策依據的是多種路徑屬性 (Path Attributes) 與商業策略，而非單純的連線頻寬或跳數。
