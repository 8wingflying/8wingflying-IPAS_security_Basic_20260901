# spoofing攻擊


#### 歷屆試題 1
```
關於 IP 位址欺騙(IP address spoofing)，下列敘述何者較正確？
(A) 利用資料庫弱點冒用他人 IP
(B) 透過變造封包等手法，以偽冒他人的 IP
(C) 不會因為 IP 重複導致系統錯誤
(D) 利用 IP 清單避免使用者遭受攻擊
```

#### 歷屆試題 2
```
下列何者最能描述「ARP 詐騙(ARP Spoofing)」的攻擊手法？ 
(A) 改寫目標伺服器上的帳號密碼 
(B) 竄改 DNS 伺服器的 IP 紀錄 
(C) 竄改區域網路中 MAC 與 IP 對應 
(D) 強行中斷 TCP 三向交握(Three-way Handshake)
```
#### 模擬試題 3
```
關於 MAC 位址欺騙（MAC Spoofing），下列敘述何者較正確？
(A) 透過發送偽造的廣播封包，以污染區域網路內其他設備的位址快取表
(B) 藉由修改作業系統的設定，改變網路卡對外宣稱的實體位址以繞過存取控制
(C) 利用竄改封包中的來源 IP 位址，向目標主機發動反射型阻斷服務攻擊
(D) 攔截使用者輸入的網址，將其強制重新導向至攻擊者架設的惡意網站
```

#### 模擬試題 4
```
關於 DNS 欺騙（DNS Spoofing），下列敘述何者較正確？
(A) 竄改網域解析紀錄或污染快取，將使用者查詢的合法網址導向惡意伺服器的 IP
(B) 偽造資料庫的查詢指令，藉此繞過網站伺服器的身分驗證機制
(C) 修改網路設備的出廠實體位址，藉此竊聽同網段內其他使用者的網路流量
(D) 透過發送大量帶有偽造來源 IP 的連線請求，癱瘓網域名稱伺服器
```
------------------
## 解答
| 標號 | 1 | 2 | 3| 4|
| ---| ---| ---| ---|---|
|答案| B | C | | A |
